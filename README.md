# QuantumComputingPortfolio

Small projects I am building to learn quantum computing by writing circuits
rather than just reading about them.

I am a Computer Science undergraduate at Queen's University Belfast aiming for
a postgraduate place in quantum computing. My background is software and cloud
infrastructure rather than physics, so this is partly about closing that gap
and partly about using it, since the field is short of people who can connect
quantum algorithms to real computing infrastructure.

Everything here is written by hand, and each project README records what
actually happened, including what did not work first time.

None of it demonstrates quantum advantage. The circuits are small and a
classical computer beats them comfortably. The point is understanding the
primitives and the engineering around them.

Built with Python, Qiskit and the Amazon Braket SDK.
